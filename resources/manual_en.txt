1. INTRODUCTION
==============================

RAMFlux is a memory monitoring and optimization tool for Windows.
It provides real-time system memory information, cache cleaning
capabilities, and management of high-RAM processes.


==============================
2. INSTALLATION
==============================

⚠️ The installer MUST be run as Administrator.

Run the MSI installer as Administrator and follow the on-screen
instructions. RAMFlux will be installed in Program Files and a
shortcut will be created in the Start Menu.

The installer includes RAMFluxHelper.exe, a privileged helper
process that performs memory cleaning operations with maximum
privileges. On the first run, the helper auto-registers a
Scheduled Task (on-logon) so subsequent logons do not require
UAC prompts. The helper's named pipe is secured with a
restrictive DACL (SYSTEM and Administrators only) and verifies
the client's session ID to prevent unauthorized access.

Requirements:
- Windows 10 or 11 (64-bit)
- 4 GB RAM (minimum)
- 200 MB disk space

3. MAIN INTERFACE
==============================

RAMFlux is organized into tabs at the top of the window:

- Dashboard: system overview
- Processes: process list with memory usage
- Leak Hunter: memory leak detection
- Memory Map: physical memory page distribution
- System Info: detailed system information
- I/O: per-process and system-wide I/O rates
- Console: event log and diagnostics
- Heatmap: visual process memory treemap (v2.14.0)
- Forecast: pressure prediction and AI metrics (v2.23.0)
- Health: system health index (v2.25.0)
- Plugins: DLL plugin management (v2.21.0)

The status bar at the bottom shows:
- Current optimizer status
- Cleaning statistics
- Game mode indicator
- Helper process status (connected/disconnected)

==============================

6. LEAK HUNTER TAB
==============================

Monitors processes for memory leaks:
- Lists processes with abnormal memory growth
- Shows current usage, peak, and growth rate
- Alerts when a process exceeds the configured threshold

The alert threshold can be adjusted in Settings
(Leak Detection > Alert Threshold).


==============================
7. MEMORY MAP TAB
==============================

Displays physical memory page distribution:
- Active: pages in active use
- Standby: cached pages (ready for reuse)
- Modified: modified pages
- Modified No-Write: modified pages without pending write
- Transition: pages in transition
- Zeroed: zeroed pages
- Free: free pages
- Bad: defective pages

Each category shows a progress bar and size in GB.

- Kernel Memory (paged and non-paged)
- Virtual Memory (used/total)

Auto-updates every telemetry cycle.

11. HEATMAP TAB
==============================

The Heatmap tab (v2.14.0) displays a visual treemap of all running
processes, where each block represents a process:
- Block size: proportional to the process Working Set (memory in use)
- Block color: green (low) → yellow → orange → pink (high RAM ratio)
- Foreground process: highlighted with a pink border
- Hover: shows tooltip with full name, PID, Working Set, Private
  memory, CPU%, and thread count
- Legend: header shows overall RAM usage % and total used/total GB

The heatmap auto-updates every 2 seconds alongside the dashboard.

New in v2.14.1:
- EcoQoS (Efficiency Mode): puts background processes into CPU
  efficiency mode via SetProcessInformation(ProcessPowerThrottling);
  reduces power consumption and heat on notebooks (Win 10 1809+)
- Gentle Standby Clean: chunked standby cleaning with disk queue
  guards (queue <1.5) and sleep intervals between chunks; elevates
  active process page priorities before flushing
- Adaptive Standby Orchestration (3-tier): Tier 1 (HF critical +
  high pressure) → gentle clean; Tier 2 (HF critical + standby >1GB)
  → selective clean; Tier 3 (standby >2GB preventive) → gentle clean
- 6 audit fixes: 2 CRITICAL (GetLastError after LocalFree), 2 HIGH
  (missing FILE_FLAG_OVERLAPPED, disablePrivilege wrong constant),
  2 MEDIUM (readOk unconditional TRUE, predictFuture data race)

New in v2.14.0:
- Standby List Inteligente: selective standby cache cleaning that
  preserves pages belonging to critical processes (foreground,
  high-memory apps) by elevating their page priority before flushing
- NUMA Optimization: automatically detects NUMA topology and pins
  game/miner processes to the best NUMA node (most free memory,
  least L3 cache contention)
- Hard Fault Predictor 2.0: uses a 30-sample sliding window with
  linear regression to predict hard fault rate 30 seconds ahead;
  preemptively triggers cleaning before I/O storms occur
- Process Memory Firewall: sets per-process memory limits via
  Windows Job Objects; detects memory leaks (200MB growth over 10
  consecutive samples) and quarantines offending processes with
  CPU throttling
- System File Cache Tuner: dynamically reduces the system file
  cache during gaming (128MB) and mining (64MB) workloads, then
  restores original values when the workload ends
- Memory Compression Manager: proactively switches the compression
  store to MaxPerformance mode during gaming/mining; expands the
  decoder pool automatically when hit rate is low

14. PLUGINS TAB
==============================

The Plugins tab (v2.21.0) manages optimization DLL plugins:

- Table with loaded plugins: name, version, status
- Buttons: Refresh (reload list), Execute (run all), Reload
  (reload DLLs)
- Plugins are executed automatically in the Scheduler loop

To add a plugin:
1. Place the .dll file in the plugins/ folder
2. The plugin must export createPlugin() / destroyPlugin()
3. PluginManager loads automatically on initialization

15. SETTINGS
==============================

Access via File > Settings.

Profile:
- Economy: maximum power saving
- Balanced: balanced default optimization
- Performance: maximum cleanup
- Gaming: anti-stutter mode
- Custom: manual settings

Behavior:
- Auto-optimization: enables automatic adaptive cleaning
- Game Mode Detection: detects running games
- Auto-detect full-screen games: detects full-screen apps
- Start Minimized: starts minimized to tray
- Start with Windows: starts with Windows boot
- Notification: show notification after cleaning
- Responsiveness Slider: adjust system responsiveness level
  (0=Very Low, 1=Low, 2=Normal, 3=High)
- I/O Monitoring: enables the I/O Dashboard tab

Polling: update interval (200-5000 ms)

Leak Detection: alert threshold for memory leaks (MB)

Auto-Clean Threshold: free memory threshold for auto-clean

Clean Areas: select areas to clean (Standby, Modified,
Working Sets, File Cache, Combined List, Defrag)

ProBalance: lowers priority of memory-heavy processes

Startup Optimization: initial clean after system startup

Scheduled Cleaning: schedule regular deep cleaning

Process Suspend/Resume: allows suspending and resuming processes
by PID. Suspended processes are moved to the standby list and
consume no CPU time. Resume restores normal execution.

CPU Rate Limiting: sets a hard CPU usage cap (1-100%) via
Windows Job Objects for processes that exceed a configurable
memory threshold.

Power Plan Automation: automatically switches between Windows
power plans based on system activity. Switches to High
Performance during gaming/heavy load, Balanced during normal
use, and Power Saver on battery.

Network QoS: sets per-process network priority (DSCP tagging)
for processes. Priority levels: Very Low, Low, Normal, High.
High priority is recommended for games and real-time apps.


==============================
16. GAME MODE & MINING MODE
==============================

Game Mode: when enabled, RAMFlux detects running games and:
- Reduces automatic cleaning frequency
- Prioritizes game performance
- Avoids aggressive cleaning during gameplay
- Activates NUMA optimization (pins game to best NUMA node)
- Reduces system file cache to 128MB for lower latency
- Sets compression store to MaxPerformance mode
- Detection can be automatic (full-screen) or by known game list

Mining Mode (v2.14.0): similar optimizations for cryptocurrency
miners:
- Reduces system file cache to 64MB
- Pins miner process to best NUMA node
- Applies Process Memory Firewall limits to prevent memory leaks
  from crashing the system
- Activates selective standby cleaning to preserve miner pages


==============================
17. PROBALANCE
==============================

ProBalance monitors high-memory processes. When a process
exceeds the configured threshold, its priority is lowered
to BELOW_NORMAL, freeing resources for other processes.
When the process memory usage drops, the original priority
is restored.

Configuration:
- Enable in Settings > ProBalance
- Adjust memory threshold (128-4096 MB)


==============================
18. PROCESS RULES
==============================

The Process Rules Engine lets you create persistent rules that are
automatically applied to matching processes whenever they are
detected. Rules are saved in Settings and persist across restarts.

Rule types:
- CPU Priority: sets the process CPU priority class
- IO Priority: sets the process I/O priority
- Page Priority: sets the process page priority (Superfetch)
- CPU Affinity: sets which logical CPUs the process may run on
- Memory Priority: sets the process memory priority
- Suspend: suspends the process (moved to the standby list and
  stops consuming CPU) — v2.44.2
- Resume: resumes a suspended process — v2.44.2

Workload scope (v2.44.2):
- Each rule can be restricted to a detected workload type
  (Game, Mining, Heavy or Office) via the Workload Condition
  field
- The rule only applies when the active system workload matches
  the configured one; a value of 0 (default) applies to any
  workload

Matching patterns:
- Exact name: "chrome.exe" matches only chrome.exe
- Wildcard: "chrome*" matches any process starting with "chrome"
- Wildcard: "*notepad*" matches any process containing "notepad"

Adding a rule:
1. Go to File > Settings > Process Rules
2. Click "Add Rule"
3. Select the type, value, and process name pattern
4. Check "Enabled" to activate

Rules are applied automatically when a matching process is
detected (every 5 seconds) and reverted when the rule is removed.


==============================
19. CPU AFFINITY MANAGER
==============================

The CPU Affinity Manager provides a visual interface to select
which logical CPU cores a process may use.

Usage:
1. Go to File > Settings > Process Rules
2. Add or edit a "CPU Affinity" rule
3. Click "Select Affinity" to open the affinity picker
4. Check/uncheck the desired CPU checkboxes
5. Use "Select All" or "Clear All" shortcuts

The dialog shows one checkbox per logical CPU, arranged in
rows of 8 CPUs.

20. PROCESS WATCHDOG
==============================

The Process Watchdog continuously monitors process memory
consumption and performs automatic actions when a configured
threshold is exceeded.

Configuration:
1. Go to File > Settings > Watchdog Rules
2. Click "Add Watchdog Rule"
3. Define:
   - Pattern: process name pattern (e.g. "chrome*")
   - Threshold (MB): Working Set memory limit
   - Duration (ms): minimum time above threshold before acting
   - Action: action to perform

Available actions:
- Terminate: ends the process
- Restart: terminates and restarts the process automatically
- Suspend: suspends the process (pauses execution) — v2.44.2
- Resume: resumes the suspended process — v2.44.2
- Set CPU Priority: changes CPU priority
- Set IO Priority: changes I/O priority
- Set CPU Affinity: changes CPU affinity
- Log: only logs the event (no action)

Suspend/Resume actions are never applied to RAMFlux itself,
to critical system processes, or to low PIDs (PID <= 4).
Suspended processes can be resumed manually from the Processes
tab (context menu).

The watchdog checks all processes every 5 seconds.


==============================
21. POWER PLAN AUTOMATION
==============================

Power Plan Automation automatically switches the Windows power
plan based on detected system activity:

- High Performance: activated when gaming or CPU-intensive
  workloads are detected
- Balanced: default during normal desktop use
- Power Saver: activated when running on battery

Configuration:
1. Go to File > Settings
2. Enable "Power Plan Automation"
3. The active power plan is displayed in the System Info tab
4. Manual override is possible via Windows power tray icon

The power plan is restored to the previous plan when the
triggering activity ends.


==============================
22. NETWORK QOS
==============================

Network QoS assigns DSCP (Differentiated Services Code Point)
tags to processes, allowing Windows to prioritize network
traffic.

Priority levels:
- Very Low (DSCP 0): background transfers
- Low (DSCP 8): non-critical traffic
- Normal (DSCP 0): default
- High (DSCP 46): Express Forwarding — recommended for games,
  VoIP, and real-time applications

Configuration:
1. Go to File > Settings
2. Enable "Network QoS"
3. Rules can be configured per process (see Process Rules)


==============================
23. RESPONSIVENESS SLIDER
==============================

The Responsiveness Slider lets you control the trade-off between
background throughput and foreground responsiveness.

Levels:
- 0 (Very Low): maximum background throughput, can feel sluggish
- 1 (Low): balanced with background bias
- 2 (Normal): balanced (default)
- 3 (High): maximum foreground responsiveness, ideal for gaming
  or interactive work

Adjust via Settings > Behavior > Responsiveness Slider.
Changes take effect immediately.

24. TROUBLESHOOTING
==============================

RAMFlux won't open:
- Verify Visual C++ Redistributable is installed
- Check the Console tab for error messages

Cleaning doesn't work:
- RAMFlux.exe runs without admin rights; cleaning operations
  are performed by RAMFluxHelper.exe, which must be running
- If the helper is not running, cleaning will be unavailable
  (monitoring continues normally)
- To start the helper: run any cleaning action — RAMFlux will
  prompt to launch the helper (UAC required once)
- Verify the Scheduled Task exists and is enabled:
  schtasks /query /tn "RAMFluxHelper"
- Verify Superfetch/SysMain service is running

RAMFluxHelper is not starting automatically:
- The helper registers a Scheduled Task on first run. If the
  registration failed, reinstall the MSI as Administrator.
- To manually recreate the task, run the helper once as
  Administrator: RAMFluxHelper.exe

Application closes unexpectedly:
- Run diagnostics in Settings > Behavior
- Check the Console for error messages
- Update to the latest version

"Access Denied" when cleaning:
- RAMFluxHelper.exe is not running or has insufficient privileges
- Launch the helper by clicking "Launch Helper" in the cleaning
  prompt, or run RAMFluxHelper.exe as Administrator manually
