# RAMFlux — Intelligent Memory Orchestrator for Windows

Real-time memory monitoring and optimization tool for Windows 10/11.

### Requirements
- Windows 10 or 11 (64-bit)
- 4 GB RAM minimum
- Administrator privileges recommended

## Features
- Real-time memory dashboard with charts and pressure scoring
- Smart memory optimization and deep cleaning
- Auto-Optimize with adaptive background cleaning
- ProBalance — reduces priority of memory-heavy processes
- Leak Hunter — detects abnormal memory growth
- File cache and memory map analysis
- Game Mode with automatic detection
- Custom profiles (Economy, Balanced, Performance, Gaming)
- Scheduled cleaning and startup optimization
- Detailed system information
- System tray with background operation
